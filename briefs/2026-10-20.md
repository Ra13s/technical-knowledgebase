# Run brief — 2026-10-20

The strongest engineering idea from this run is that **a crashed worker does not prove its last operation failed**. Temporal's Pi coding-agent experiment records each tool-call claim before execution. If a worker dies without a persisted result, the resumed session treats the outcome as unknown and checks the real state before considering a retry. A lease also prevents an abandoned worker from overwriting the recovered transcript. This turns ambiguous failures into explicit recovery states instead of optimistic retries.

Kong's agent-review system and Meta's Thin Orchestrator tell a related story. Kong moved model/skill selection into deterministic triage after multiple reviewer agents repeated the same code exploration; it reports lower review costs. Meta keeps a narrow routing protocol around reusable domain agents and explicit workflow templates. In both cases, orchestration is predictable software while domain work remains agentic. A larger agent fleet is not necessarily a better one.

An October Java API/Kafka harness experiment offers a caveat: extra executable feedback can improve a smaller model's successful completion rate, but adds substantial expense when a more capable model already meets the acceptance criteria. Keep independent final tests and measure optional development-time feedback by task and model.

StackAI's document-ingestion design transfers durable execution to RAG. Each file moves through retryable download, parse, chunk and index stages. Async parser callbacks signal a waiting workflow; documents stay in blob storage and expensive parser results are cached by content and parser settings. Its first-party report of much lower failure rates is encouraging, but other parts of the pipeline also changed.

The most reusable additions are [durable agent tool effects](../topics/ai/durable-agent-tool-effects-and-fencing.md) and [durable document ingestion](../topics/platform/durable-document-ingestion-pipeline.md). We also extended [deterministic agent orchestration](../topics/ai/deterministic-outer-loop-agent-platform.md) using Meta's seven-step thin router.
