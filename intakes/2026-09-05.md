# Intake — 2026-09-05

## New things we can use now

### Narrow-contract background coding agent

Checkout.com's Agent HAL shows a practical operating model for background agents: explicit triggers, a pre-edit task-readiness gate, a fresh-context reviewer before PR creation, continuous CI/rebase maintenance, and the same human/security gates as normal PRs.

Canonical entry: [`Narrow-contract background coding agent`](../topics/ai/narrow-contract-background-coding-agent.md)

### Deterministic outer loop for coding-agent platforms

Dropbox Nova separates probabilistic agent work from deterministic workflow control: explicit repo snapshot, isolated session, declarative validation commands, validation outside the model loop, bounded retries, and publication controlled by the surrounding platform.

Canonical entry: [`Deterministic outer loop for coding-agent platforms`](../topics/ai/deterministic-outer-loop-agent-platform.md)

### Precision-first multi-stage AI code review

Uber uReview treats review as a pipeline rather than a single prompt: specialized generators, independent grading, per-category/language thresholds, semantic deduplication, low-value category suppression, and production feedback/evals.

Canonical entry: [`Precision-first multi-stage AI code review`](../topics/ai/precision-first-multi-stage-code-review.md)
