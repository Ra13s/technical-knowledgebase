# Intake — 2026-08-17

## New things we can use now

### Hibernate `@EmbeddedTable`

For Hibernate ORM 7.2+, an entire `@Embedded` value can be mapped to a `@SecondaryTable` with one `@EmbeddedTable("table_name")` instead of repeating table mappings across attribute/association overrides.

**Concrete use:** Spring Boot 4.x / Hibernate 7.x entities where an embeddable lives wholly in a secondary table.

### Safe switching over externally evolving sealed APIs

An exhaustive switch over a sealed type can still fail at runtime with `MatchException` when the type comes from an independently upgraded dependency that adds a permitted subtype after the consumer was compiled.

**Concrete rule:** omit catch-all cases for closed hierarchies we own and co-compile, but either use an explicit catch-all or guarantee recompile/test-on-upgrade for externally versioned sealed hierarchies.

### MCP compatibility migration + conformance tests

For MCP protocol upgrades, adapt versions at the transport boundary and delegate both old and new protocol paths to the same tool/domain implementation. Validate the public contract with the official `@modelcontextprotocol/conformance` runner and keep small custom checks only for gaps not yet covered by the runner.

**Concrete use:** add MCP conformance as a CI target for any MCP client/server we own, especially during spec/SDK migrations.

## Experiments worth trying

1. **`@EmbeddedTable` mapping test:** in a Hibernate 7.2+ sandbox, map an embeddable to a secondary table with `@EmbeddedTable`, then assert generated insert/select SQL and compare the mapping to the equivalent override-based version.
2. **Sealed API compatibility test:** compile a consumer against v1 of a sealed hierarchy, add a subtype in v2 without recompiling the consumer, and demonstrate the `MatchException`; repeat with an explicit catch-all to validate the decision rule.
3. **MCP CI check:** add `npx @modelcontextprotocol/conformance server --url ...` to a small MCP server build and establish how to pin the runner version and surface failures in CI.
